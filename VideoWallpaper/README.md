# VideoWallpaper (C++)

Простые видеообои для Windows 10/11. Внешних библиотек не нужно: только Win32 и Media Foundation, которые уже есть в Windows.

## Возможности
- Видео на фоне рабочего стола (за иконками), зацикливается, без звука.
- Иконка в трее: выбрать видео, пауза/продолжить, автозапуск с Windows, выход.
- Двойной клик по иконке в трее тоже открывает выбор видео.
- Запоминает последнее видео в `VideoWallpaper.ini` рядом с exe.

## Сборка
1. Установите **Visual Studio Build Tools** с компонентом «Разработка классических приложений на C++».
2. Откройте «x64 Native Tools Command Prompt» и выполните:
   ```
   build.bat
   ```
3. Получится `VideoWallpaper.exe`.

## Ограничения
- Форматы зависят от кодеков Windows: надёжно работают MP4 (H.264), WMV, AVI, MOV. MKV и WebM могут не открыться.
- Видео вписывается в экран с чёрными полосами (без растягивания).
- Если Explorer перезапустился (например, после сбоя), обои могут пропасть: перезапустите VideoWallpaper.
- Код не проверялся на реальной Windows в среде разработки. При ошибках сборки или поведения пришлите текст ошибки.
